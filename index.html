Wahoo Map Styles

Share and discover custom map styles (vtm-elemnt.xml) for your Wahoo ELEMNT. Thinner cycle paths, calmer colours, your own look.

View on GitHub Browse styles

How it works

The look of the ELEMNT map (colours, line widths, visible features) is controlled by a VTM render theme, not by the map tiles. The default theme is bundled in the firmware. Put a file at maps/vtm-elemnt/vtm-elemnt.xml on the device to override it. Delete it to go back to the default.

Mostly reverse-engineered, not official Wahoo documentation. Keep the original file and use at your own risk. Background: Map styling.

Default styles per firmware

FirmwareFiles
18001 (BOLT2, 180.01) vtm-elemnt.xml, vtm-elemnt-enhanced.xml, rendertheme.xsd

Have the default of another firmware? Please add it.

Using a style

  1. Download the vtm-elemnt.xml (or vtm-elemnt-enhanced.xml) matching your firmware.
  2. Connect your ELEMNT over USB (MTP).
  3. Create maps/vtm-elemnt/ on the device and copy the file there.
  4. Restart the device.
